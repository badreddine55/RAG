RAG incremental indexing test fixture

The sample_project folder has four files:
  calculator.py      Python code with functions and a class
  guide.md           Markdown documentation
  architecture.rst   reStructuredText documentation
  empty.py           Zero-byte file to test empty-file filtering

To test without touching your vLLM dataset:
1. Extract sample_project to your RAG project, for example data/raw/rag-test/sample_project.
2. Temporarily change Parccer().load_files(...) to point to that folder.
3. Use a separate Indexer path such as data/test_index.json.
4. Run python3 -m src twice. First run: 3 new files, 0 unchanged. Second run: 0 new files, 3 unchanged.
5. Edit guide.md and run again: 1 modified file, 2 unchanged.
6. Delete architecture.rst and run again: 1 deleted file, 2 unchanged.

Expected JSON structure (not exact chunk boundaries):
{
  "config": {"chunk_size": 2000, "code_overlap": 0, "doc_overlap": 0},
  "files": {
    ".../calculator.py": {
      "mtime_ns": 123456789,
      "chunks": [{"page_content": "...", "metadata": {"source": ".../calculator.py", "file_name": "calculator.py", "suffix": ".py", "start_index": 0}}]
    }
  }
}

Actual mtime_ns and chunk content are generated by your code.
